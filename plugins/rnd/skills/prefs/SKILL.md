# /rnd:prefs — 全局编码偏好

把用户跨项目的个人编码倾向落到本机 `~/.claude/CLAUDE.md`(Claude Code 每会话、每项目自动加载)。
**只动这一个文件;内容由用户填;私有、只在本机,绝不进任何仓。**

## 步骤
1. 解析 `$HOME/.claude/CLAUDE.md` 是否存在。
2. **不存在** → 创建并写入下面的「空模板」。然后告诉用户:
   「已建好 `~/.claude/CLAUDE.md`,填上你的前端/后端偏好即可;下个会话起,我在任何项目写代码都会照它来。」
3. **已存在**:
   - 先读它。若**已含**「我的全局编码偏好」段 → **不要覆盖**,把现有那段展示给用户,问要不要改。
   - 若**不含** → 在文件**末尾追加**下面的模板段(保留原有全部内容)。
4. **铁律:绝不 clobber** 用户已有的 CLAUDE.md 内容——只新建或追加,不整体覆盖。写前如会动到已有文件,先把将追加的内容给用户看一眼。

## 空模板
```text
# 我的全局编码偏好

> Claude Code 每个会话、每个项目都会自动加载本文件。填上你的偏好,我写代码时照着来;
> 留空的项按项目既有风格 / 常规默认处理。

## 前端
- 框架/语言:
- 样式方案:
- 组件风格:
- 状态管理:
- 不要用:

## 后端
- 语言/框架:
- 分层/架构:
- 错误处理:
- 日志/配置:
- 不要用:

## 通用
- 命名/注释/函数粒度:
- 测试:
```

## 说明(可一并告诉用户)
- 这覆盖「主循环(我)直接写代码」这条路——主循环每次自动读 `~/.claude/CLAUDE.md`。
- 想让 rnd **子代理**也强制遵守:以后在项目里 `/rnd:init` 时把这些偏好并入该项目 `.claude/rnd-profile.json` 的 `conventions`(本命令不自动做)。
- 内容私有,**不会**进 rnd 公开仓;换机器装上插件后再跑一次 `/rnd:prefs` 即可重建模板。
